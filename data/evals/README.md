# CSRA Capability Evaluation Dataset

- `capability_cases.jsonl`: 40 synthetic, human-reviewable customer support test cases (5 per capability across 8 capabilities).
- Format: JSONL (`case_id`, `capability`, `difficulty`, `messages`, `context`, `tools`, `expected_behavior`, `expected_output`, `expected_tools`, `scoring_criteria`).

> **Note**: These initial cases are synthetic and should be reviewed by domain experts before treating scores as final ground truth.
